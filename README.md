# Car Market - Django

A car marketplace web site. Solo project made during a Django course at university. Started in October 2026, still in progress.

## Tech stack
Python, Django, SQL, HTML, CSS

## Done
- Admin panel superuser
- Adding car data

## Planned
- Car list and detail pages, search and filter
- User registration and login
- Image upload

## How to run
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
